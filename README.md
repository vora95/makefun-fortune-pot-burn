One kind, funny fortune for a houseplant (115 characters), written by a deterministic program (`main.ts`, Node stdlib only, no network):

> Soon the morning sun will find your leaves first on this windowsill, and your keeper will take credit for the glow.

`main.ts` validates the entry (1–120 chars, single line, no trailing newline), writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`, and verifies the file on disk is byte-identical (sha256 logged).
